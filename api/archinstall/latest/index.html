## Module archinstall This module installs a linux from scratch by the arch way. You will end up in ligtweigth linux with pacman as packet manager. You can directly install into a given blockdevice, partition or any directory (see command line option "--target"). Note that every needed information which is not given via command line will be asked interactively on start. This script is as unnatted it could be, which means you can relax after providing all needed informations in the beginning till your new system is ready to boot. Start install progress command (Assuming internet is available): ```bash curl \ https://raw.githubusercontent.com/thaibault/archinstall/main/archinstall.sh \ >archinstall.sh && \ chmod +x archinstall.sh ``` Note that you only get very necessary output until you provide "--verbose" as commandline option. Examples: Start install progress command on first found blockdevice: ```bash arch-install --target /dev/sda ``` Install directly into a given partition with verbose output: ```bash arch-install --target /dev/sda1 --verbose ``` Install directly into a given directory with additional packages included: ```bash arch-install --target /dev/sda1 --verbose -f vim net-tools ``` ### Function ai_add_boot_entries Creates an uefi boot entry. ### Function ai_append_temporary_install_mirrors Appends temporary used mirrors to download missing packages during installation. ```bash >>> local AI_MOUNTPOINT_PATH="$(ai_bl_doctest_mktemp --directory)/" >>> mkdir --parents "${AI_MOUNTPOINT_PATH}etc/pacman.d" >>> ai.append_temporary_install_mirrors "https://a.tld https://b.tld" >>> cat "${AI_MOUNTPOINT_PATH}etc/pacman.d/mirrorlist" Server = https://a.tld/$repo/os/$arch Server = https://b.tld/$repo/os/$arch ``` ### Function ai_cache Cache previous downloaded packages and database. ```bash >>> local AI_MOUNTPOINT_PATH="$(ai_bl_doctest_mktemp --directory)/" >>> local AI_CACHE_PATH="$(ai_bl_doctest_mktemp --directory)/" >>> mkdir --parents \ >>> "${AI_MOUNTPOINT_PATH}var/cache/pacman/pkg" \ >>> "${AI_MOUNTPOINT_PATH}var/lib/pacman/sync" >>> touch "${AI_MOUNTPOINT_PATH}var/cache/pacman/pkg/"{a.pkg.tar.xz,b.pkg.tar.zst} >>> touch "${AI_MOUNTPOINT_PATH}var/lib/pacman/sync/core.db" >>> ai.cache >>> ls "$AI_CACHE_PATH" a.pkg.tar.xz b.pkg.tar.zst core.db ``` ### Function ai_changeroot This function emulates the arch linux native "arch-chroot" function. ### Function ai_changeroot_to_mountpoint This function performs a changeroot to currently set mountpoint path. ### Function ai_commandline_interface Provides the command line interface and interactive questions. ```bash >>> ai.commandline_interface --help +bl.doctest.contains +bl.doctest.multiline_ellipsis ...
